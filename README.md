# AI Engineer Roadmap — 6 Month Command Center

A single-file, local-first dashboard based on the Ultimate AI Engineer Roadmap 2026.

## Features
- 19 sections: Phase 0–17 + Capstone
- Topic and project checkboxes
- Overall progress bar and statistics
- Search and status/phase filters
- Per-phase typed notes with autosave
- Upload PDF/image/text notes from iPad
- Uploaded files stored in IndexedDB on the device/browser
- Export/import a JSON backup
- Responsive/touch-friendly layout for iPad
- No server, database, API key, or account required

## Run

Install Node.js, then run:

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. For a production build, use `npm run build`.

For iPad: host the built `dist` folder with any static web host and open the URL in Safari.

## Important
Because this is local-first, browser storage is device/browser-specific. Use **Export backup** regularly. The backup contains your typed notes, progress, and uploaded files.
